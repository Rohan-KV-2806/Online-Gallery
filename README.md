# Online Gallery
## HTML and CSS

### What I Did

I built an online gallery web app using only HTML and CSS. No AI tools—just me, W3Schools, and GeeksforGeeks.

**Project Structure:**
- `index.html`
- `style.css`
- `images/` folder with background and gallery images (cat1.jpg to cat8.jpg)

I used Flexbox to arrange the image cards so they wrap nicely on smaller screens. Added some basic styling to buttons and cards to make it look decent.

This is simple but I will be updating this more often.
